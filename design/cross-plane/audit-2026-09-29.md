## 一、审计方法

四路并行完整通读（非摘录），判定基线为当前权威架构：

1. DC 侧只有 Alloy 一个进程（**本次已被 `collection-topology.md` 修订为 Alloy + Vault Agent + collector**）；Job Scheduler / Scheduler / Agent / OTel Collector / Target Syncer / DC Proxy / Zone Query Proxy 全部废弃
2. 存储是独立层，每个存储实例 = vmstorage + vmalert + Alertmanager 共部署；Worker 安装时选存储（可多选）并指定 prime
3. 网区存储模式 Mode A/B/C 整体废弃
4. 目标发现由 DC 网关通过 http_sd 提供（非 file_sd）
5. 查询路径：Query Gateway → DC 网关 vmselect → fan-out 所有 vmstorage
6. 告警链路：Alloy → vmstorage → vmselect → vmalert（仅 prime）→ AM（零配置）→ am-bridge → Kafka 六 topic → Flink 收敛引擎 → 平台
7. 带外心跳独立于告警链路，覆盖存储侧全链路 + Flink
8. 凭据合并入实例记录（DEC-016）
9. Alloy clustering（gossip + 一致性哈希）替代 slot / VRRP / Gossip 协商 / epoch fencing
